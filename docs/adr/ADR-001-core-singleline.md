# ADR-001: Core v2 为唯一主线

**状态**: 接受（Accepted）

**日期**: 2026-08-29

## 背景
当前项目包含 Legacy 与新框架并行路径，若继续双路径并行演进，迁移、测试和恢复策略会长期失去收敛条件。为实现 G-1/G0 交付，需要统一执行主线。

## 决策
在 G-1 后续、G0 及以后阶段中，`F:\mxd\product\maple-automation-core` 为唯一受控主线。Legacy 仅作为数据/策略参考与最小适配来源，不再承载新增控制逻辑。

## 实施范围
- 新特性、动作控制、恢复策略、事件回放、发布流程必须在 Core v2 内实现。
- Legacy 仅允许：
  - 复用可复用算法或资产（不重构）；
  - 提供迁移接口（adapter）用于比对与回退。

## 影响
- 所有输入控制入口仅保留 Core v2 架构。
- 任何新需求必须附带对应 ADR/任务链接（若触碰关键边界需先更新 ADR）。
- 进入 G1 之前，G0 结束前需完成治理门禁：`主线确认 + 测试/回放 + 证据绑定`。
