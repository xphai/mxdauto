# ADR-002: FramePacket 为时序一致性最小单元

**状态**: 接受（Accepted）

**日期**: 2026-08-29

## 背景
多源采集与模型推理会引入异步性：若缺少统一时序载体，故障复盘将失去确定性，动作也难以可靠关联到“观测时刻”。

## 决策
`FramePacket` 定义为系统内最小时序数据单元，所有观测、感知、决策、执行事件链必须基于该单元传播。

## 最低字段约束
- `session_id`（会话）
- `frame_id`（帧序号）
- `captured_at`（单调/统一时间）
- `source`（采集来源）
- `geometry`（尺寸与 ROI）
- `health`（采集质量）

## 实施要求
- 任何观测批次与动作事件必须可追溯到 `frame_id`。
- 陈旧、重复、断序帧必须可检测并剔除或标记。
- 在记录与回放中必须保留 FramePacket 完整链路。

## 影响
- 决策链可回放；
- `FramePacket` 缺失或未就绪即视为暂停决策状态；
- 所有异常与恢复流程可基于 frame 轨迹复盘。
